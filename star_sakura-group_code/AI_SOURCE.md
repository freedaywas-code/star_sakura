# AI 功能源码留档

此目录原先包含一份带有大量重复文件和未解决合并冲突的完整项目副本。重复的用户、作品、委托、私信、部署、前端和启动文件已清理，其可用功能已经适配到原项目目录。

这里只保留 AI 后端模块的干净源码快照，方便核对 AI 功能来源。项目运行时请使用原项目中的以下文件：

- `backend/apps/recommendations/`：同一 AI 会话中的日常聊天、站内功能语义消歧和平台问答，以及中文意图与预算识别、真实在售作品检索、开放委托匹配、为本人开放委托基于公开资料匹配画师、官方/用户自定义 OpenAI-compatible 模型路由、加密凭据、公网地址校验、本地降级、回复来源记录、迁移与测试
- `frontend/index.html`：AI 助手页面和入口
- `frontend/app.js`：会话历史、令牌刷新、SSE 流式对话，以及可打开委托详情或画师主页的结果卡片
- `frontend/styles.css`：AI 助手桌面端与移动端样式
- `run.py`：支持 SSE 的本地前端代理

真实密钥不保存在本目录或 Git 中。官方模型请在原项目的 `backend/.env` 中配置；用户自定义密钥由主项目后端加密保存，读取接口不会回传明文。

同一 AI 对话会根据问题和上下文自然切换日常聊天、真实在售作品检索、开放委托匹配、本人委托的画师匹配和平台问答，不需要切换不同助手。平台问答覆盖账号、搜索、互动、关注私信、委托和“我 → 设置 → 智能体模型”。

预算条件是硬过滤；本地助手不会用零匹配或超出预算的作品、委托凑数，联网模型返回的作品、委托和画师 ID 也必须属于当前真实候选范围。画师匹配只使用公开资料；AI 不会泄露他人报价、邀请留言或成交价，也不会代用户执行报价、邀请或选中画师等操作。
